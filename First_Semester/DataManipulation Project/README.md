# Interactive Data Visualization System

A comprehensive web application that transforms raw student data into interactive visual graphs using Flask backend and interactive web frontend.

## Project Overview

This project allows students to:
- Enter student names and marks
- Select from multiple graph types (Bar, Line, Pie, Scatter)
- Customize graph appearance (colors, size)
- View real-time visualizations

## Features

✨ **Interactive User Interface**
- Clean, modern design with responsive layout
- Real-time data entry and validation
- Multiple graph visualization options

📊 **Graph Types**
- Bar Chart - Compare student marks
- Line Chart - View performance trends
- Pie Chart - Percentage distribution
- Scatter Plot - Relationship analysis

🎨 **Customization Options**
- Custom color selection
- Adjustable graph size (Small, Medium, Large)
- Real-time preview

🔐 **Data Management**
- Add/Delete student records
- Clear all data with confirmation
- Data validation

## Technology Stack

### Frontend
- **HTML** - Structure and semantic markup
- **CSS** - Styling with responsive design
- **JavaScript** - Interactive functionality

### Backend
- **Python** - Server-side logic
- **Flask** - Web framework
- **Matplotlib** - Graph generation
- **Flask-CORS** - Cross-origin requests
